# Try it / credits

## Try the upstream build

This showcase is a **fork walkthrough**. To build your own brain:

1. Start from Linda's repo: https://github.com/LindaHaviv/second-brain
2. Follow [docs/TUTORIAL.md](https://github.com/LindaHaviv/second-brain/blob/main/docs/TUTORIAL.md) Part I
3. Load **your** public content first; add private scopes only after Lab 4
4. Wire local MCP for Cursor / Claude Desktop (Lab 7)

My fork: https://github.com/ramonacraft/second-brain

## What this showcase is not

- Not a hosted public MCP (local stdio only)
- Not private or financial data
- Not a claim that every portfolio integration is fully wired end-to-end — READMEs are honest about live vs roadmap links
